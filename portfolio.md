# VetriTN - Tamil Nadu Citizen Services Hub

## 🎯 Project Overview
**VetriTN** is a modern, bilingual web application that serves as a one-stop portal for Tamil Nadu government services. Citizens can search, track, and apply for 50+ government schemes including revenue certificates, pensions, scholarships, and grievance redressal.

**Live Demo**: [vetrin.saravanan.dev](https://vetrin.saravanan.dev)  
**GitHub**: [github.com/yourusername/vetrin](https://github.com/yourusername/vetrin)  
**Portfolio**: [saravanan.dev/projects/vetrin](https://saravanan.dev/projects/vetrin)

## ✨ Key Features

### 1. **Smart Service Search**
- Real-time search across 50+ TN govt schemes
- Category filters (Revenue, Social Welfare, Education, etc.)
- Bilingual (English ↔ தமிழ்) support

### 2. **Eligibility Checker**
- Detailed eligibility criteria popup
- Required documents list
- Income limits and rules

### 3. **Comprehensive Dashboard**
- Personalized services based on location/community
- Recent applications tracking
- Favorites and quick actions

### 4. **Responsive Design**
```
📱 Mobile-first (90% usage)
💻 Desktop optimized
🌙 Dark/Light mode
🔄 PWA ready
```

### 5. **Modern Tech Stack**
```
Frontend: Vite + React 18 + TypeScript
UI: shadcn/ui + Tailwind CSS + Lucide Icons
State: React Context + TanStack Query
Build: Vite + PostCSS
Form: React Hook Form
Deployment: Vercel/Netlify
```
